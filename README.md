FitPulse – Fitness & Wellness App

Overview

FitPulse is a modern fitness and wellness mobile app designed to help users build healthy habits, track their progress, and achieve their fitness goals.

This project was created as part of my **UI/UX Design Internship at SoftGrowTech**.

 Features

- Personalized fitness goals
- Workout tracking
- Progress monitoring
- Daily streak tracking
- Breathing & wellness exercises
- User profile and settings

Design

Designed in **Figma** with a modern dark UI and bright lime accent color.

**Primary Color:** `#D7FC00`

 Tools

- Figma
- UI/UX Design
- Wireframing
- Auto Layout
- Prototyping
